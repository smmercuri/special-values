# Special Values of $L$-functions

This repository contains formalized proofs of known cases of various conjectures 
about special values of $L$-functions. 
The prototypical case is the well-known values of the Riemann zeta function
$$
  \frac{\zeta(2n)}{(2\pi)^{2n}} = (-1)^{n + 1}\frac{B_{2n}}{2(2\pi)!}\in\mathbb{Q}, \\
  \zeta(-n) = -\frac{B_{n + 1}}{n}\in\mathbb{Q},
$$
where $B_n$ are the Bernoulli numbers. 

The generalizations of such statements to other motives, input values, and 
degree of specification of the algebraic value are covered by the Deligne, 
Beilinson, and Bloch-Kato Tamagawa Number conjectures.
